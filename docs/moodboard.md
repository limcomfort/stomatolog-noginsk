# Мудборд — Clinical Luxe

Тип клиники: **стоматология полного цикла**, рейтинг 4,25, 58 отзывов. Задача — не «медцентр из шаблона», а частная практика, которой доверяют на годы.

## Направление

Тёплый кремовый фон + глубокий графитово-зелёный + латунный акцент + серифные заголовки. Ощущение клиники с историей, а не федеральной сети.

## Токены

- Фон: `#FCFAF5`, `#F7F3EA`, `#EFE8DA`
- Тёмный: `#12211C` / `#1B322B`
- Акцент: `#B08850` (brass), светлый `#D9BE92`, тёмный для текста `#8C6A3A`
- Текст: `#2C463D` основной, `#5B6F67` вторичный
- Радиусы: 16 / 24 / 32 / 44 px. Тени мягкие, большой blur, малая альфа.

## Типографика

- Заголовки: Playfair Display 500–600, `letter-spacing: -0.02em`, `clamp()`.
- Текст: Manrope 400–600, 16–18 px, `line-height: 1.65`.
- Надзаголовки: 11–12 px, uppercase, `0.22em`.

## Микроанимации

- `Reveal`: `opacity 0 → 1`, `y 24 → 0`, 0.75 s, easing `cubic-bezier(.22,1,.36,1)`.
- Hover: подъём карточки на 4 px + усиление тени; иконка поворачивается на −5°.
- Линия под преимуществом: `scale-x 0 → 1` на hover.
- Счётчики рейтинга и отзывов — при попадании в viewport.
- `prefers-reduced-motion`: все анимации отключены.
